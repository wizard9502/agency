# Agency

**The permissionless launchpad where creators, builders, and educators launch tokens that give people real ownership, skills, and tools.**

Multi-chain (Arc-first liquidity + BNB Chain), seamless Privy wallets.

## Vision
Agency combines three powerful verticals under one roof:
- **CreatorEquity** — creators launch tokens with real ownership & revenue share
- **OpenTools Factory** — builders fund open-source tools & public goods
- **SkillForge** — educators launch tokens for skills, courses, and learning paths

## Tech Stack (planned)
- Frontend: Next.js + Tailwind + Privy
- Smart contracts: Solidity (EVM) on Arc, BNB, later Arbitrum/Base/Robinhood Chain + Solana
- Liquidity: Arc-first
- Indexing: The Graph / custom

## MVP Feature Set
- Permissionless token launch (3 categories)
- Bonding curve trading
- Privy embedded wallet + external wallet connect
- Discovery feed with filters (Creators / Tools / Skills)
- Arc primary liquidity + BNB support
- Basic profile & launch form

## Phased Roadmap
**Phase 1 – Landing + Core (current)**
- Minimalist landing page
- Project scaffolding
- Brand & positioning

**Phase 2 – MVP Launch**
- Smart contract factory + bonding curves on Arc + BNB
- Privy integration
- Launch form + discovery
- Basic trading UI

**Phase 3 – Expansion**
- Category-specific modules (revenue share, unlocks, milestones)
- Additional chains (Arbitrum, Base, Robinhood Chain, Solana)
- Advanced discovery, leaderboards, social features

**Phase 4 – Scale**
- Cross-chain liquidity
- Governance / fee switch
- Partnerships & growth
